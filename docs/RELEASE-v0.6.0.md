# Web開発版 v0.6.0 / iOS Nook UI 更新

2026年11月8日。ソースの更新記録です。**公開サイトはWeb v0.5.0で、v0.6.0の配信とiPhone版の一般配布はまだ行っていません。**

## Web追加開発

- `duplicates.mjs`：同容量・先頭末尾64KBの指紋で絞った後、1MBずつ全バイトを比較して完全一致を確認。各組1本以上と「残す」を除いたコピー選択。中止・進捗表示。似た動画の判定は対象外。
- `media-tools.mjs`：Canvas / MediaRecorder / Web Audioで元動画を残す圧縮コピー。長辺1280px / 960px、対応形式はブラウザで判定。ファイル内の音声を処理し、マイク・カメラは利用しません。
- メモリ出力128MB上限、対応PCの直接保存、中止時の後片付け、元動画と同名や同じ参照先への上書き拒否。
- コピー保存・対応環境の共有。クラウド自動転送・転送完了判定は対象外。

## iPhone試作の更新

- 既存RecSortアイコン、クリーム色・濃い文字・ライム色を使ったNook UI。
- 動画サムネイル・容量カード・少量選択・フィルター・検索・判断ボタン。
- ライブラリ設定、整理のヒント、削除前の確認、圧縮と保存画面を統一。
- `AVFoundation`で圧縮・コピー、元動画を残し、結果のプレビューと写真へのコピー保存・共有。
- 「7日後」にした動画も現在の選択から解除。サムネイルの時間表示の切れを修正。

## 確認した範囲

Webロジック24、ファイル操作15、ワークフロー9、メディア補助処理10、重複照合9の各検証を通過。重複は同じ指紋でも中間部分が異なるケースを含めて確認しています。

Web実画面で4秒の自己生成テスト動画を約9MBから約1MBに変換し、映像・音声と元動画が残ること、中止と再実行を確認しました。直接保存・全ブラウザ・長い動画は未検証です。

iOSはXcode 27.2 / iOS 27.0 / iPhone 18 Pro Simulatorでビルド・操作確認。9.2MB→3.7MBの圧縮、コピーの写真保存、検索・保護・保留・アプリ内最終確認、架空1,700件の表示と5件選択を確認しました。iOSモデル12検証も通過しています。

PC実ファイル削除、iOS削除完了・復元、実機、iCloud同期、App Store / TestFlight配布は未検証です。詳しくは[検証記録](VERIFICATION.md)。
