# Web v0.5.0とiOS試作

## Web版

- 「あとで確認」に見直し日（今日・明日・7日後・30日後）を設定。期限前の保留はおすすめから除外し、期限が来ても自動削除しない。
- 「今日の5本」で、現在の一覧条件から見直し時期を優先して最大5件を選択。
- 「一覧をこのブラウザに保存」で名前・容量・日時だけを保存。再読み込み後は元動画なしで判断を見直せる。保存一覧は実ファイルの現在状態を保証せず、再生・削除には再接続が必要。
- 対応PCではユーザーの操作でフォルダハンドルをIndexedDBに記憶。次回は再許可して読み込む。自動で削除権限を取得しない。解除ボタンあり。
- 大量選択の可視・非表示件数確認を改善。1,700件のテストファイル読み込みと保存復元をブラウザで確認。
- 削除以外の選択肢と、未送信の利用メモ保存を追加。圧縮・クラウド転送は未実装。

## iOS

[native/RecSort-iOS](../native/RecSort-iOS/README.md)にSwiftUI/PhotoKitによる試作を追加。シミュレーター向けのビルドと表示、テスト動画の再取得を確認しています。実機や一般配布の完成を意味しません。
