# Web v0.4.0（PC削除機能ベータ）

2026年11月7日。v0.3.3の候補提示・CSV機能を維持し、専用フォルダ選択から読み込んだ動画に限り、対応PCブラウザでの直接削除を追加しました。

## 安全のための条件
- 動画の選択、パス・容量の確認、復元不可についての同意、削除ボタン操作、書き込み許可、最終確認を経て実行。
- 「残す」は対象外。ファイルハンドルの同一性と容量・更新日時を再確認。
- 参照はメモリのみ。文字列のパスを削除先に変換しない。フォルダの再帰削除をしない。
- 成功したものだけ一覧から除去。失敗と未処理は残し、残りの処理を中止できる。
- ゴミ箱移動ではない。削除後の復元や空き容量反映は保証しない。

## 検証
既存ロジック24アサーション成功。test-file-access.mjsの15シナリオ成功。未確認・「残す」・権限拒否・参照先変更・容量や日時の変更・部分失敗・中止・ファイル消失・サブフォルダ・模擬1,700件などをモックで検証しました。ブラウザの模擬画面で「残す」の除外、削除1件・失敗1件の表示、失敗したものと残す動画の保持を確認。モック用コードは公開distに含めません。

実ファイルの削除、実際の権限ダイアログの操作、Windows、iPhone実機1,700件は未検証です。模擬データの検証を実機動作保証とは扱いません。削除直前の確認と削除の間に別アプリがファイルを更新する競合を完全には防げません。同容量・同日時で変更した内容は判別しません。

## 学校提出物との関係
動画・提出PDF・補足Q&Aはv0.3.3の記録です。公開サイトのschool-demo/に当時の削除なし版を保持しています。先生に新機能を案内する際は、v0.4.0の追加機能と上記の未検証事項を合わせて伝えてください。

## 未対応
写真アプリの動画削除、iPhone専用アプリ、重複検出、撮影日の正確な読み取り、圧縮、クラウド退避は引き続き未実装です。
