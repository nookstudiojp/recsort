# 要件と設計

2026年11月8日更新。[公開版・開発版・iOS試作の区別](../README.md#versions)を前提に記載します。

## 課題と利用者

録画で容量がいっぱいになったときに、整理候補をおすすめしてほしい。動画が増え、大切なものを守りながら何から整理するか迷う人に、理由を見て少量ずつ判断できる仕組みを提供します。

## 要件への落とし込み

一覧と容量・日時の把握、理由付き候補、残す・見直すの判断、確認を挟む整理を基本とします。削除だけでなく元動画を残した圧縮・コピーも追加開発しています。候補を不要と断定せず、自動削除・期限後の削除・空き容量の保証は行いません。

## Web構成

HTML / CSS / JavaScriptの静的アプリです。動画はアップロードせず、選ばれたFile参照から一覧・プレビュー・変換を端末内で処理します。

| モジュール | 役割 |
| --- | --- |
| `app.js` | 読み込み・画面・状態・検索・ソート・選択・確認・プレビュー |
| `core.mjs` | 動画種別、候補理由、表示容量、CSV生成 |
| `decisions.mjs` | パス・容量・最終更新日時をキーに判断を対応付け、残すを選択から除外 |
| `workflow.mjs` | 見直し日、少量選択、一覧保存・復元、任意のフォルダ参照保存 |
| `file-access.mjs` | 対応PCのフォルダ走査・確認後の削除 |
| `duplicates.mjs`（v0.6開発版） | 全バイトを比較する完全一致照合とコピー選択 |
| `media-tools.mjs`（v0.6開発版） | Canvas / MediaRecorder / Web Audioでコピー変換 |

Webの初期候補条件は最終更新から90日以上、2×1024³バイト以上、0バイトのいずれかです。日数と容量は変更できます。「残す」と期限前の保留を候補から除外します。動画内容・視聴履歴・撮影日は判定しません。重複の全バイト照合は利用者が操作したときだけ実行します。

判断・見直し日・任意の一覧情報はlocalStorage、任意の対応PCフォルダ参照はIndexedDBに保存します。サンプル判断はメモリのみです。一覧保存には動画本体・削除可能なファイル参照・重複の検証済みフラグを含めません。復元一覧からの再生・削除には再接続が必要です。

## iOS構成

| ファイル | 役割 |
| --- | --- |
| `RecSortApp.swift` | SwiftUIの一覧・設定・確認・圧縮結果・共有画面 |
| `NookUI.swift` | 色・カード・ボタン・サムネイル取得 |
| `LibraryStore.swift` | PhotoKit権限、許可範囲の取得、容量確認、判断保存、削除依頼、書き出しの状態管理 |
| `VideoRecord.swift` | 候補、保護、並べ替え、表示容量 |
| `VideoExporter.swift` | AVFoundationのコピー・圧縮、中止、生成コピー管理 |

写真への許可が維持されていれば起動時に許可範囲を取得します。判断はPHAssetの識別子とUserDefaultsで保持。お気に入り・残すを保護し、保留にした動画は現在の選択からも外します。撮影日はPhotoKitの取得値です。

容量確認は同時4件まで、サムネイルは表示中の行で取得し画面外のリクエストを中止。容量確認・サムネイルのためのiCloud自動取得は行いません。取得できなければ容量未確認とし、0バイトと扱いません。書き出しでのみ利用者が明示的にiCloud取得を許可できます。

## 確認と安全

PCの直接削除は、専用フォルダ選択、同意、書き込み許可、最終確認を経ます。keep、参照先・容量・日時の変更を再確認し、失敗時は残りを中断します。ゴミ箱には移しません。確認と削除は原子的操作ではなく、同容量・同日時の内容変更まで検出する仕組みはありません。

iOSは選択内容、同意、アプリの最終確認、必要なOSの確認を経てPhotoKitへ削除を依頼します。確認・処理中のライブラリ変更通知を保留し、直前に対象の存在と保護を再確認します。iCloud写真の削除は同期先にも反映され得ます。

圧縮は元動画を変更せず別コピーを作ります。保存先の再生を確認し、元動画を整理する場合は別の削除操作を行います。コピー保存だけでは使用容量は減りません。ブラウザの長時間変換・直接保存やiOSの実機・削除完了は検証が残っています。[検証範囲](VERIFICATION.md)

## UIと今後

Nook Studioのクリーム色・ライム色・濃い文字、理由付き候補、押しやすい判断、少量選択を軸にしています。不要な動画を自動で決めず、利用者の判断を支援します。今後、実機・大量実動画の負荷、誤操作や判断の負担、保存先の確認を検証し、聞き取りから対象用途を絞ります。
